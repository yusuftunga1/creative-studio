An Awwwards-inspired creative production studio web application built with **React 19, TypeScript, Tailwind CSS v4, GSAP, and Lenis**.

---

## ✨ Architectural Features & Interaction Mechanics

- 🎭 **Curtain Page Transitions:** Fullscreen wiping screen transitions inspired by Barba.js.
- 🧲 **Magnetic Physics Buttons:** GSAP-driven magnetic cursor attraction effects on interactive elements.
- 🎯 **Smooth Lerp Custom Cursor:** Lag-free linear interpolated cursor follower with interactive expansion states.
- 📜 **Lenis Smooth Scrolling:** Inertial wheel scrolling and smooth anchor jumping.
- 📐 **Numbered Service Hierarchy:** Alternating `01`, `02`, `03` split discipline showcases with watermark outlines.
- 🎬 **Integrated Cinema Showreel:** High-definition video player modal overlay.

---

## 🛠️ Quick Start

```bash
# Clone the private repository
git clone https://github.com/yusuftunga1/creative-studio.git
cd creative-studio

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
