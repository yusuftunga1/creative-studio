## ✨ Features

- 🎬 **Cinematic & Immersive Hero Experience**:
  - High-impact display typography with gradient glow accents.
  - Interactive magnetic "Play Showreel" trigger and city/time status indicators.
  - Custom stylized dual-ring cursor with smooth mouse tracking.
- ⚡ **GSAP Magnetic Physics**:
  - Interactive magnetic pulling effect on buttons and navigation items.
  - Realistic spring physics on mouse hover and leave states.
- 🌊 **Buttery Smooth Inertial Scrolling**:
  - Integrated with **Lenis Smooth Scroll** for unified momentum and high-refresh scrolling.
- 🧭 **Intelligent ScrollSpy Navigation**:
  - Real-time viewport position calculation (`getBoundingClientRect()`).
  - Active section pill indicator with smooth layout transitions.
- 🚁 **Dynamic Services & Multi-Discipline Grid**:
  - **Motion & Cinematic Storytelling**: Full-spectrum narrative and commercial productions.
  - **Aerial & Dynamic Motion**: High-speed heavy-lift and custom FPV drone operations.
  - **Interactive Web & Virtual Spaces**: 3D WebGL interfaces and creative frontend technology.
- 🏎️ **Curated Portfolio Showcase**:
  - Filterable multi-category gallery with hover zoom depth and client meta indicators.
- 🤝 **Selected Brand Collaborations**:
  - Minimalist dark-themed partner grid featuring top global luxury and tech brands.
- 📬 **Interactive Project Inquiry Terminal**:
  - Built-in multi-field contact interface with instant response feedback.
- 🔒 **Safe & Clean Open-Source Setup**:
  - Zero hardcoded secrets, clean `.gitignore`, standard MIT open-source license.

## 🚀 Quick Start

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yusuftunga1/creative-studio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd creative-studio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open in your browser:**
   Visit `http://localhost:5174/` or the address shown in your terminal.
